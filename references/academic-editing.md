# 中英文学术润色

使用现稿和用户授权的修改范围。可以处理中文期刊稿、英文期刊稿以及已有英译稿。按目标期刊、学科和范文确定术语、语气和格式。

1. **先从现稿提取提纲。** 读完整节和全文相关部分，分别摘出本节的主要判断、每段想说明的事及其证据。找出偏离章节任务、证据接不上判断或句间跳跃的地方。拟定修改方案并等用户授权。若用户只要求语句润色，结构建议单独提出。
2. **再改论证与表达。** 在授权范围内先处理影响理解的结构问题，再调整措辞。让每段围绕一个主要信息，把判断接回已有证据和适用条件。新术语初次出现时要能理解，相邻句要有清楚的关系。中文用严谨的学科术语。英文用清楚的主语、具体动词和一致的技术用语，按期刊处理拼写和时态。按 [句子与措辞规则](prose-style.md) 修订冗余和机械衔接。
3. **逐项回核现稿。** 核对数据、单位、公式、引用、图表号、验证条件、因果方向和不确定性。含义不明、证据不足或需要科学判断的地方标给用户。明确批准的科学内容变动须在复核中说明。
4. **交付并迭代。** 从修改稿重新提取提纲，检查段落能否共同支撑本节主要判断，以及证据与判断是否配对。结合内置 `academic-humanizer` 修订后，按[定稿复读](prose-style.md#final-read)重读整段，核对是否出现用套话或抽象名词掩盖实际做法、或句子变顺但丢失依据的情况。只授权润色措辞时，把无法靠措辞修复的结构或证据缺口另外指出。提交润色稿和必要的变更说明。多轮修改沿用对应章节的档案。

论证与段落检查参考 [Research Paper Writing Skills](https://github.com/Master-cai/Research-Paper-Writing-Skills/tree/main/research-paper-writing)，已整理成本 Skill 的中英文通用润色流程。参见 [上游 MIT 许可](vendor/research-paper-writing/LICENSE)。
