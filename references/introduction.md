# Introduction 的表达示例

先确定句子在论证中要完成的任务，方括号按稿件事实填写。引用紧跟它所支持的工作、发现或限制。

| 用途 | 可改写的英文表达 |
| --- | --- |
| 说明问题的重要性 | `In [setting], [problem] limits [specific decision or outcome].` |
| 概括已有工作 | `Studies using [approach A] have examined [question A], while those using [approach B] have focused on [question B].` |
| 指出具体缺口 | `Prior studies have assessed [known aspect]. Whether [specific relationship] holds under [condition] remains unclear.` |
| 提出目标和范围 | `We examine [research question] in [population, setting, or period] using [design].` |
| 概括回应缺口的做法 | `We combine [component A] with [component B] to address [specific gap].` |
| 说明具体改进 | `The analysis extends [prior approach] by incorporating [specific change], which allows us to assess [question].` |
| 说明贡献 | `The study provides [specific evidence or tool] for evaluating [question] in [setting].` |
| 简要指引后文 | `Section [number] describes [data or method]. Section [number] presents [results].` |

写缺口时，限定已有研究的对象、条件或可回答的问题。写贡献时，表述本研究实际解决的问题。篇章安排按读者需要选用。
