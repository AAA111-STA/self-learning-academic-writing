# Discussion 的证据与句式示例

## 把数字写成论证

一段可沿着「判断 → 关键数据 → 文献或机制证据 → 对研究问题的意义」推进。每一步应接住前一步中的对象或发现。只有确实服务于读者理解的数据、比较和解释才写进段落。

- **解释幅度。** 遇到「提升了 60%」一类表述，先核实提升的指标、起点、比较对象和相对变化的计算口径。比例指标变化时，区分相对百分比与百分点。与其他论文比较时，把引用放在它具体支持的判断旁边。
- **解释原因。** 若前人用方法 A，本文改进 A 或用方法 B 回答类似问题，具体指出改变了什么。报告控制条件下能检验的差异。用不同样本、尺度或设计得出的结果，交代这些差异如何限制直接比较。
- **落到贡献。** 说明这项发现澄清了哪个问题，或让哪项判断更有依据。提出机制时，交代证据来自本文的直接检验、间接观察还是已有研究，并据此选择措辞。可用概念类比帮助读者理解，但对应关系须清楚，结论落到具体科学问题。

## 英文句式按论证用途选用

方括号中的内容按稿件事实填写。每段以研究对象和证据推进，句式随之调整。

| 用途 | 可改写的表达 |
| --- | --- |
| 概括关键发现 | `Using [approach], we found that [key finding] under [condition].` |
| 解释结果幅度 | `Relative to [baseline], [metric] changed from [baseline value] to [observed value] under [evaluation condition].` |
| 与文献一致 | `The direction of the association is consistent with that reported by [Author] for [comparable setting].` |
| 与文献不同 | `Whereas [Author] reported [finding A] at [scale A], we observed [finding B] at [scale B].` |
| 解释可能的差异来源 | `This difference may reflect [documented difference in sampling, measurement, or design].` |
| 说明方法改进 | `Under the same [evaluation conditions], [method B] yielded [specific change] relative to [method A].` |
| 报告与预期不一致的结果 | `Although we expected [predicted pattern], the estimate for [effect] was [result], with [measure of uncertainty].` |
| 指出理论或应用含义 | `The pattern suggests that [theoretical prediction or practical decision] may depend on [condition].` |
| 解释局限并提出下一步 | `Because [constraint], the results apply most directly to [scope]. [Follow-up design] would allow us to assess [remaining question].` |

涉及有无差异、显著性、因果或模型改进时，逐项核对句子中的比较对象、分析层级和结论强度。用同一条论证线串起章节，检查开头所提的问题能否在解释、综合和局限中得到回应。

中文示例：「［发现］与［文献］在［可比条件］下报告的结果一致」（明确一致的是哪项发现）；「这一差异可能与［有据可查的样本或设计差异］有关」（限定解释强度）；「由于［限制］，目前只能判断［适用范围］」（交代局限对判断的影响）。
