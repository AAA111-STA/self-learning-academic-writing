# Abstract 的表达示例

按句子承担的任务选词和组织表达，方括号用稿件事实填写。方法与结果句宜直接交代动作和发现，研究价值句写明具体应用或推断范围。

| 用途 | 可改写的英文表达 |
| --- | --- |
| 聚焦缺口 | `Whether [relationship] holds under [condition] remains unclear.` |
| 从已有进展引出问题 | `Existing [approaches] address [specific task], but [remaining issue] persists under [condition].` |
| 说明研究目的 | `We examined how [factor] relates to [outcome] in [setting].` |
| 介绍核心方法 | `We used [data or design] to estimate [quantity] at [scale].` |
| 说明方法工作 | `We developed [method] and evaluated it on [dataset] against [baseline].` |
| 报告实质性发现 | `[Outcome] increased with [factor] across [observed range].` |
| 报告可比的定量结果 | `Under [validation condition], [metric] was [value] for [method] and [value] for [baseline].` |
| 报告相对变化 | `On [dataset] under [test condition], [method] reduced [error metric] by [percentage] relative to [baseline].` |
| 概括证据支持的结论 | `The findings suggest that [interpretation] within [observed conditions].` |
| 说明价值与范围 | `The estimates can inform [specific decision] in [setting].` |

- 用 `examine` 或 `compare` 陈述目的。只有确实检验了假设或性能时才用 `test` 或 `evaluate`。
- 按实际操作区分 `measure`（测量）、`calculate`（计算）和 `estimate`（估计）。用 `develop` 表示开发，用 `apply` 表示采用已有方法。
- 用 `find`、`observe` 或具体的结果动词描述观察到的发现。用 `suggest` 或 `indicate` 表达有边界的解释。`demonstrate` 和 `confirm` 适用于正文提供了相应验证的判断。
- 表达已完成的工作与本研究观察到的结果时，通常用过去时。陈述仍然成立的现状或解释当前发现的含义时，可用现在时。与指定范文的学科惯例和目标期刊的写法保持一致。
